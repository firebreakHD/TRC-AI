# TRC-AI

Persönliches, lokal betriebenes Assistenzsystem für Home Assistant OS. Der Entwicklungsstand 0.3.0 enthält die Dokumentenverarbeitung und Wissensdatenbank mit PostgreSQL und Qdrant, das Control Center und die kompatible HTTP-Schnittstelle für n8n. [Netzwerkoptionen und Dienstprofile](docs/NETWORK.md) werden im Control Center verwaltet.
