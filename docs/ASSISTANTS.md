# Assistenten

| Profil | Standard |
| --- | --- |
| Allgemeiner Assistent | Neutral und klar, Standard Deutsch. |
| JARVIS | Technisch präzise, direkt, gelegentlich trockener Humor. Männliche Stimme als künftige Profileigenschaft. |
| FRIDAY | Freundlich, professionell und organisiert. Weibliche Stimme als künftige Profileigenschaft. |

Die Auswahl im Chat bleibt für die Unterhaltung erhalten. Administration → Routing und Assistenten bietet Namen, Beschreibung, Modell, Anweisung, Sprache, vorgesehene Stimme, bevorzugten Modus und Werkzeugfreigaben. Ein leeres Modellfeld übernimmt das gemeinsame Ollama-Modell. Live-Sprachfunktionen gehören zur späteren Integration.
